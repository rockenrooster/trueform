Trueform — UI reference

Visual reference for docs/plan/04-ui-ux.md. Four key screens at 360 × 780 dp, dark theme. The waveform and the equaliser curves are computed by the script at the bottom from the same rules the app uses (three-band colour mix, RBJ filters, corrected band gains, automatic preamp), so shapes and numbers are honest. CSS variables in :root are the design tokens.
